# Clínica Kavaná · Apresentação do sistema

Apresentação interativa do sistema da Clínica Kavaná: site, agenda, prontuários, documentos, gestão, área do paciente e segurança.

**Abrir:** https://henrickbessa.github.io/kavana-apresentacao/

- Setas, espaço ou clique avançam; **I** abre o índice; **F**, tela cheia; **?** mostra os atalhos.
- Passe o mouse nas legendas para destacar a área da tela; clique numa tela para ampliar.

Telas reais do sistema, com **dados fictícios** de demonstração (nomes "Exemplo"). Nenhum dado real de paciente.
